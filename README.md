# Job Description Evidence Retrieval

This repository contains a frozen job-description corpus and reproducible
experiments on retrieving source evidence from job postings. It compares
BM25, dense retrieval, hybrid fusion, and reranking for questions with different
levels of lexical overlap. It is a research codebase, not a deployed job-search
application.

## Introduction

The benchmark asks whether a retriever can find the passage containing a
specific job requirement when the source posting is unknown. It evaluates
source-evidence retrieval, not generated answers or all potentially relevant
jobs.

## Data

The canonical snapshot in [`data/canonical/jobs.jsonl`](data/canonical/jobs.jsonl)
contains **240 non-internship postings** from **78 companies**, with 60 postings
in each family: Software Engineering, Data Science / Analytics, AI Engineering,
and Product Management. The postings were collected from public ATS sources;
this is a quota-based sample, not a complete or random job-market dataset.

## Results

V2 uses 80 source facts and 160 paired questions. V3 reranks the combined BM25
and dense Top-20 candidates using the same frozen benchmark.

| Method | High Hit@5 | Low Hit@5 | High MRR@5 | Low MRR@5 |
| --- | ---: | ---: | ---: | ---: |
| BM25 | 0.963 | 0.663 | 0.910 | 0.574 |
| Dense (BGE-M3) | 0.600 | 0.313 | 0.483 | 0.276 |
| Hybrid (RRF) | 0.925 | 0.625 | 0.690 | 0.384 |
| BM25 + Dense reranker (V3) | 0.975 | 0.763 | 0.883 | 0.659 |

The reranker raised low-overlap Hit@5 from 0.663 (BM25) to 0.763. V3 is an
exploratory extension evaluated on the same queries, not an independent test.
Metrics reflect retrieval of the originating evidence only; other relevant
postings were not labeled. See the detailed
run reports generated by the V2 and V3 workflows for confidence intervals and
failure cases. Generated reports and run outputs are not committed to this
repository.

## Getting Started

Requires Python 3.11 or newer. Retrieval experiments use local model weights
and a compatible GPU.

```bash
uv venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\Activate.ps1
uv pip install -r requirements.txt
```

The YAML files in `config/` already define the experiment settings, and the
frozen V2 questions and labels are included under `data/benchmarks/jd_v2/`.
Model weights and generated run outputs are not included. To reproduce V2 with
the supplied benchmark:

```bash
# Build retrieval passages; this derived file is not included in the repository.
python -m scripts.run_experiment prepare

# Download pinned Qwen3-8B and BGE-M3 weights if they are not already cached.
python -m scripts.run_experiment cache-models

python -m scripts.run_experiment retrieve --run-id jd_v2_run_01
python -m scripts.run_experiment report --run-id jd_v2_run_01
```

Optional V3 reranking:

```bash
# Run once if the pinned reranker weights are not already cached locally.
python -m scripts.run_rerank_v3 cache-model

# Run the reranking experiment.
python -m scripts.run_rerank_v3 run
```
